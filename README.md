# A305X — Born to Disobey

A retro-futurist Miami rebellion brand for apparel, coffee, strange objects, and classified ideas.

## Product flow

The website is the brand experience. Real products, prices, inventory, and checkout should live in Shopify. Each card in **Drop 0001** can link directly to its matching Shopify product page.

## Deployment

Static site with no build step. The root `index.html` is ready for Vercel.
